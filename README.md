# BlockNova

A mobile-first block puzzle game built with Godot 4.

## Current prototype
- Portrait mobile layout
- 10x10 board
- Three shape choices
- Touch and mouse placement
- Row and column clearing
- Score and game-over/restart flow

## Run
Open this folder in Godot 4.x and run `scenes/main.tscn`.

## Roadmap
1. Polish touch drag/drop and placement preview
2. Add persistent records, combos, sound and haptics

BlockNova is an original project inspired by the block-puzzle genre. It does not use Block Blast branding or assets.
